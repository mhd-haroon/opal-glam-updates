# OPAL GLAM — Official Software Updates

**Product:** OPAL GLAM — Billing & Barcode Studio  
**Developed & Licensed by:** **BlankFive Innovations**

This repository distributes signed software updates and release manifests (`opalglam_update.json`, Windows `.zip`, and Android `.apk`) for **OPAL GLAM — Billing & Barcode Studio**.

## How Auto-Updates Work
- **Windows Desktop (`OpalGlamBarcode.exe`)**: Open **Help → Check for Updates...** (or click the **⬆ Update** badge when notified on launch) to download, verify SHA-256 checksums, back up your database automatically, and install the latest release.
- **Android Mobile App**: Open **Settings → Check for App Updates** to update directly from GitHub Releases or over Shop Wi-Fi via your Host PC.
